# 语音转文字 Skill

把用户提供的原始音频或带音轨视频，自动转换为带时间戳的逐字稿，并为后续总结、Call 复盘、情绪分析、会议纪要等任务提供可复用证据底稿。

## 支持范围

原则上支持 **任何 FFmpeg 可解码的音频/视频媒体文件**，常见格式包括：

- 音频：M4A、AAC、MP3、WAV、FLAC、OGG、OPUS、WEBM、AMR 等
- 视频：MP4、MOV、MKV、WEBM 等（自动提取音轨）

## 默认行为

- 原始媒体文件就是足够输入，不要求用户自行提供逐字稿。
- 先统一标准化为 16kHz 单声道 WAV，再进入 Whisper。
- 长音频默认 base 模型跑完整时间轴；关键片段可用 small 模型二次精转。
- 输出 TXT / SRT / JSON / manifest，并通过源文件 SHA-256 复用缓存。
- 销售 Call 可继续交给逐字稿证据分析、丢单节点、心理变化、声学情绪曲线等下游流程。

`runtime/` 中的大模型和二进制不建议提交到 Git；Skill 会优先复用本地缓存，并可通过 bootstrap 流程自动补齐。
